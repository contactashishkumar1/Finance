Getting Started

Introduction

Every international bank transfer relies on a set of standardised codes and identifiers to ensure funds reach the correct account, at the correct bank, in the correct country. Without these identifiers, cross-border transfers would have no reliable mechanism for routing.

The two most important international banking identifiers are the SWIFT/BIC code — which identifies the bank — and the IBAN — which identifies the specific account. Understanding how these codes work, how they differ from domestic identifiers like routing numbers and sort codes, and how international transfers are actually routed is essential for anyone sending or receiving money internationally.

Banking Infrastructure

What Is SWIFT?

SWIFT stands for Society for Worldwide Interbank Financial Telecommunication. It is a global financial messaging network that enables banks and financial institutions to securely communicate and exchange payment instructions with each other across international borders.

Crucially, SWIFT does not move money itself. It is a messaging system — a secure, standardised way for banks to send instructions to each other. The actual movement of funds happens through the banking system, triggered by these messages.

SWIFT was established in Belgium in 1973 and is co-operatively owned by its member financial institutions. It serves thousands of financial institutions across the globe and processes millions of messages per day covering payments, securities transactions, and treasury operations.

When you initiate an international bank transfer, your bank uses the SWIFT network to communicate the payment instruction to the recipient's bank (often via one or more intermediary banks). The SWIFT code of the recipient's bank tells the network exactly where to send the message.

Bank Identifier

What Is a BIC Code?

A BIC (Bank Identifier Code) is the formal ISO 9362 standard name for the code that identifies a bank in international transactions. In practice, BIC and SWIFT code are used interchangeably — they refer to the same alphanumeric identifier.

SWIFT/BIC codes can be 8 or 11 characters. An 8-character code refers to the bank's primary office. An 11-character code identifies a specific branch. When only an 8-character code is available, "XXX" is often appended automatically by banking systems.

Account Identifier

What Is an IBAN?

An IBAN (International Bank Account Number) is a standardised format for identifying a specific bank account in an international transfer. Where the SWIFT/BIC code identifies the bank, the IBAN identifies the individual account at that bank.

The IBAN standard is defined by ISO 13616. It is widely adopted across Europe, the Middle East, and parts of North Africa, but many major countries including the United States, Canada, Australia, India, and China do not use IBANs — transfers to these countries rely on a SWIFT code plus a local account number.

Does your destination country use IBAN?

IBAN is used by most European countries, as well as many Middle Eastern and North African countries. Countries such as the USA, Canada, Australia, India, and most of Southeast Asia and Latin America do not use IBAN. For these destinations, you will need to provide the recipient's local account number alongside their bank's SWIFT/BIC code.

In countries that use IBAN — such as those within the European Union — both the SWIFT/BIC and the IBAN are typically required for an incoming international transfer. In countries that do not use IBAN — such as the United States, Australia, or India — only the SWIFT code and local account number are needed.

US Banking

Routing Number vs SWIFT Code

ABA Routing Number

A 9-digit US-specific code used to identify a bank for domestic transfers, ACH transactions, direct deposits, and cheque processing. Every US bank branch has its own routing number. The American Bankers Association (ABA) administers these codes.

021000021(Example format only)

SWIFT/BIC Code

An 8 or 11 character code used globally to identify a bank for international wire transfers. US banks use SWIFT codes for receiving international wires, even though they use routing numbers domestically. The two systems serve different purposes and different transaction types.

CHASUS33(Example format only)

When sending money to a US bank account from another country, you will typically need the recipient's SWIFT code, their routing number, and their account number. When sending domestically within the US, only the routing number and account number are required.

UK Banking

Sort Code vs SWIFT Code

UK Sort Code

A 6-digit code in the format XX-XX-XX used in the UK and Ireland to identify the bank and branch for domestic transfers, direct debits, and standing orders. Sort codes are administered by Pay.UK and are embedded within a UK IBAN.

20-00-00(Example format only)

SWIFT/BIC for International Transfers

For receiving international transfers into a UK bank account, the SWIFT/BIC code and IBAN are used. The sort code and account number are embedded within the IBAN, so they do not need to be provided separately when an IBAN is given.

Identifying Accounts

Account Number vs IBAN

A domestic account number identifies an account within a specific bank. The same account number format could theoretically exist at a different bank in a different country — without additional context, it is ambiguous in an international setting.

An IBAN solves this by embedding the country code, bank identifier, and account number into a single standardised code with built-in check digits. This makes it unambiguous and machine-readable across borders.

Aspect Domestic Account Number IBAN
Scope Identifies account within one bank Identifies account uniquely across borders
Validation Varies by bank Built-in checksum for error detection
Contains Account number only Country + check digits + bank code + account
Global availability Universal (every account has one) Only in IBAN-participating countries
European Payments

SEPA: Single Euro Payments Area

SEPA (Single Euro Payments Area) is a European payment integration framework that simplifies and harmonises euro-denominated bank transfers across participating countries. SEPA was designed to make cross-border euro payments within the participating area as simple and cost-effective as domestic transfers.

SEPA payments use the IBAN and BIC identifiers. The main SEPA payment types are:

SEPA Credit Transfer (SCT)

Standard euro bank transfers between accounts in SEPA countries. Typically settle within one business day.

SEPA Instant (SCT Inst)

Real-time euro transfers settling within seconds, available around the clock for participating banks.

SEPA Direct Debit (SDD)

Allows businesses to collect recurring euro payments from customer accounts in SEPA countries, typically for subscriptions or invoices.

SEPA includes all EU member states as well as several non-EU countries including Iceland, Norway, Liechtenstein, Switzerland, and the UK (the UK continues to participate in SEPA despite leaving the EU). SEPA applies to euro transfers only — transfers in other currencies use the standard international banking channels.

How Transfers Work

International Wire Transfers

When you instruct your bank to send an international wire transfer, the following sequence typically occurs:

1
Transfer instruction initiated

You provide the recipient's SWIFT/BIC code, IBAN (or local account number), and the transfer amount. Your bank debits your account.

2
SWIFT message sent

Your bank sends a SWIFT message (typically MT103 for single customer credit transfers) to the recipient's bank, directly or via one or more correspondent banks.

3
Correspondent banking

If there is no direct banking relationship between sender and recipient banks, the payment routes through one or more correspondent/intermediary banks. Each may apply its own fee.

4
Compliance checks

Each bank in the chain performs AML and sanctions screening before passing the transfer on. This process can add time — particularly for large or unusual transfers.

5
Recipient credited

The receiving bank credits the recipient's account. The total time from initiation to credit typically ranges from one to five business days, depending on the corridor and number of correspondent banks involved.

Banking Network

Correspondent Banking

Not every bank in the world has a direct banking relationship with every other bank. To enable cross-border payments between institutions that do not have a direct relationship, the global banking system relies on a network of correspondent banks.

A correspondent bank is a financial institution that holds accounts on behalf of other banks and executes transactions in foreign currencies on their behalf. Large global banks — particularly those in major financial centres — serve as correspondent banks for smaller regional and local banks around the world.

Each correspondent bank along the chain may deduct a fee. This is why the amount received by the beneficiary in a traditional SWIFT wire transfer can sometimes be slightly less than the amount originally sent. Modern money transfer services often work around this by using their own internal networks or local payment systems rather than routing through the full correspondent banking chain.

Routing Chain

Intermediary Banks

An intermediary bank is any bank that sits between the sending bank and the receiving bank in a SWIFT wire transfer. In practice, intermediary and correspondent bank are often synonymous terms. When initiating a transfer, you may be asked to provide intermediary bank details if your sending bank requires them.

Intermediary banks are relevant because they:

  • May charge their own fees, reducing the amount delivered to the recipient
  • Add processing time to the transfer chain
  • Perform their own compliance checks, which can cause delays
  • Are identified by their own SWIFT/BIC codes in payment instructions

The SHA, OUR, and BEN fee arrangements in a SWIFT transfer specify who bears the cost of intermediary fees:

Code Stands For Who Pays
SHA Shared Sender pays own bank's fee. Recipient pays receiving bank's fee. Most common arrangement.
OUR Our (sender's) Sender pays all fees. Recipient receives the full transferred amount.
BEN Beneficiary All fees deducted from the transferred amount. Recipient receives less than the gross amount.

Avoid These

Common Mistakes with SWIFT & IBAN

Providing only the SWIFT code without the IBAN: For countries that use IBAN, providing only the SWIFT code without the IBAN may result in rejection or significant delays. Both are typically required together.
Entering an incorrect IBAN: A single character error in an IBAN can cause the payment to fail, be rejected, or — in some cases — be credited to an incorrect account. Always verify character by character.
Confusing a routing number with a SWIFT code: A US routing number is a domestic identifier. For international wires into a US account, the SWIFT code (not the routing number alone) is required from the sender's side.
Using an 8-character SWIFT code when 11 characters are required: Some receiving banks require the full 11-character branch-specific code. When in doubt, ask the recipient to confirm the exact SWIFT/BIC code with their bank.
Assuming all countries use IBAN: Many countries — including the US, Australia, India, Canada, China, and most of Asia — do not use IBAN. Using this guide's country reference table helps determine what identifiers are required.
Sending to a closed or incorrect account number: If the IBAN is correctly formatted but the underlying account is closed or the number is wrong, the bank may return the funds — but recovery can take days or weeks and may involve fees.
Protect Yourself

Security Tips for Bank Transfers

✓ Always verify bank details independently

Before sending a large transfer, call the recipient directly using a number you already have — not one provided in the same message as the bank details — to confirm the account information.

✓ Be alert to Authorised Push Payment (APP) fraud

Scammers impersonate legitimate contacts — solicitors, suppliers, or landlords — and provide fraudulent bank details to redirect payments. Verify any new or changed payment details by phone.

✓ Send a small test amount first

For large first-time transfers to a new account, consider sending a small amount first and confirming receipt before sending the balance.

✓ Do not share your banking credentials

SWIFT codes and IBANs are used for receiving funds. Never share your online banking login, OTPs, or authentication codes with anyone claiming to verify a transfer.

✓ Verify SWIFT codes with the receiving bank

SWIFT codes are publicly available for legitimate institutions. If you receive bank details by email or message, verify the SWIFT code independently through the bank's official website or by calling them directly.

✓ Use secure connections

Always initiate transfers through official banking apps or websites accessed via secure, private internet connections. Avoid initiating payments on public Wi-Fi.

Key Terms

SWIFT & IBAN Glossary

Term Definition
SWIFT Society for Worldwide Interbank Financial Telecommunication. The global messaging network used by banks to exchange payment instructions.
BIC Bank Identifier Code. The ISO formal name for a SWIFT code. The two terms are interchangeable.
IBAN International Bank Account Number. A standardised format for identifying a specific bank account across borders, including country code, check digits, bank code, and account number.
SEPA Single Euro Payments Area. A European payment framework enabling simplified euro transfers between participating countries using IBAN and BIC.
Routing Number A 9-digit US-specific identifier for a bank or branch used in domestic ACH and wire transfers.
Sort Code A 6-digit UK/Ireland bank branch identifier in the format XX-XX-XX, used for domestic transfers.
Correspondent Bank A financial institution that provides banking services on behalf of another bank in a different country or currency, enabling international fund routing.
Intermediary Bank A bank in the payment chain between the sender's and recipient's banks. May deduct fees as the transfer passes through.
MT103 The standard SWIFT message type for single customer credit transfers (international wire payments). Banks use MT103 messages to instruct the recipient's bank to credit a specified account.
SWIFT GPI Global Payments Innovation — an initiative enhancing speed, tracking, and transparency for cross-border SWIFT payments.
ACH Automated Clearing House. The US domestic batch payment network used for direct deposits, payroll, and consumer payments.

Common Questions

Frequently Asked Questions

What is a SWIFT code?
A SWIFT code is a standard format identifier used to identify financial institutions in international wire transfers. SWIFT codes are also known as BIC codes — both terms refer to the same identifier.
What is the difference between a SWIFT code and a BIC?
There is no functional difference. BIC is the formal ISO standard name and SWIFT is the network that uses these codes. Both terms refer to the same alphanumeric identifier used to identify a bank in international transactions.
What is an IBAN?
An IBAN (International Bank Account Number) is a standardised format for identifying an individual bank account across national borders. It begins with a two-letter country code, followed by two check digits, and a series of alphanumeric characters identifying the bank and account.
How long is a SWIFT code?
SWIFT codes are either 8 or 11 characters. An 8-character code identifies the bank and country. An 11-character code additionally identifies the specific branch. If only 8 characters are known, 'XXX' is often appended.
Do all countries use IBAN?
No. IBAN is most widely used in Europe, the Middle East, and parts of North Africa. The United States, Canada, Australia, India, China, and most of Southeast Asia do not use IBAN. Transfers to these countries use a SWIFT code and local account number.
What is a routing number?
A routing number is a 9-digit code used in the United States to identify a bank for domestic ACH and wire transfers. It is US-specific and is not used internationally in the way SWIFT codes are.
What is a sort code?
A sort code is a 6-digit UK/Ireland identifier in the format XX-XX-XX used for domestic bank transfers. For international transfers into a UK account, the IBAN and SWIFT/BIC are used instead.
What is SEPA?
SEPA (Single Euro Payments Area) is a European Union payment integration initiative that simplifies bank transfers in euros across participating countries. SEPA transfers use IBAN and BIC and are generally faster and cheaper than non-SEPA international transfers.
What is a correspondent bank?
A correspondent bank is a financial institution that provides banking services on behalf of another bank in a different country. When two banks lack a direct relationship, correspondent banks route international transfers — and may charge fees along the way.
Can I send a SWIFT transfer without an IBAN?
For countries that use IBAN, you should always provide the IBAN alongside the SWIFT/BIC code. For countries that do not use IBAN — such as the US, Australia, or India — you will provide a SWIFT code with the local account number instead.
How do I find a bank's SWIFT code?
SWIFT codes are listed on a bank's official website, on bank statements, and in online banking dashboards. Verify the code with the receiving bank before initiating a large transfer.
What happens if I enter the wrong IBAN?
Entering the wrong IBAN may cause the transfer to be rejected, returned, or credited to an incorrect account. Recovery of funds can be a lengthy process. Always verify the IBAN character by character before confirming.
What is SHA, OUR, or BEN in a SWIFT transfer?
These codes define who pays correspondent bank fees. SHA (Shared) means both parties pay their own bank's fees. OUR means the sender pays all fees. BEN means all fees are deducted from the transferred amount, so the recipient receives less.
Does IBAN have a checksum?
Yes. IBANs contain two check digits (positions 3 and 4) that allow mathematical validation before processing. This helps detect simple data-entry errors. Most banking software validates the checksum automatically.
Does SWIFT move money directly?
No. SWIFT is a messaging network, not a fund transfer mechanism. It transmits standardised payment instructions between financial institutions. The actual movement of funds occurs through the banking system, triggered by these messages.
Why do international bank transfers sometimes take longer than expected?
Delays can result from compliance checks at each bank in the chain, the number of correspondent banks involved, time zone differences, local settlement cut-off times, and currency conversion processing.
Can money transfer apps bypass the SWIFT network?
Some modern transfer services use internal liquidity pools or local payment networks rather than routing through the traditional SWIFT correspondent banking chain, which can reduce fees and improve speed while still delivering funds to the recipient's bank account.
What is SWIFT GPI?
SWIFT GPI (Global Payments Innovation) enhances cross-border payment tracking, transparency, and speed within the traditional SWIFT network. Banks participating in SWIFT GPI can provide end-to-end tracking of international wire transfers.
What is SEPA Instant?
SEPA Instant is an extension of the SEPA framework that allows euro transfers to settle within seconds, around the clock. Both the sending and receiving banks must be enrolled in the SEPA Instant scheme.
What identifiers do I need to receive money from abroad?
If you are in an IBAN country, you will typically need to provide your IBAN and SWIFT/BIC code to the sender. If you are in a non-IBAN country such as the US, India, or Australia, you will need to provide your SWIFT code, local account number, and any relevant domestic routing identifier such as a routing number or IFSC.
How does an IFSC code differ from a SWIFT code?
An IFSC (Indian Financial System Code) is an 11-character code used for domestic Indian transfers via NEFT, RTGS, and IMPS. It is a domestic identifier only. A SWIFT code is used for international transfers into Indian accounts. The two serve different purposes.

Key Takeaways

Summary

Understanding SWIFT codes, IBANs, and the correspondent banking network demystifies how international transfers actually work and helps you avoid costly errors.

  • A SWIFT/BIC code identifies the bank. It is 8 or 11 characters and used globally.
  • An IBAN identifies the specific bank account. It is used in Europe, the Middle East, and parts of Africa — not universally.
  • IBAN-supported countries need both a SWIFT/BIC and an IBAN for incoming international transfers.
  • Non-IBAN countries (US, Australia, India, Canada, etc.) use a SWIFT code plus local account number.
  • SEPA simplifies euro transfers within Europe using IBAN and BIC.
  • Correspondent and intermediary banks route funds between institutions without direct relationships, and may charge fees.
  • Always verify bank details independently before initiating large transfers to protect against payment fraud.
